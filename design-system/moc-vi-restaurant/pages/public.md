# Public website override

Source direction from the Phase 3A brief overrides the generated general palette in `MASTER.md` for all public pages.

- Background: warm cream `#f7f3e9`; foreground: deep olive `#28372b`.
- Primary: muted olive `#39583f`; accent: natural wood `#805b38`.
- Use cream surfaces and fine stone-colored borders; avoid red, glossy shadows, gradients as decoration, glassmorphism, dense badges and SaaS-style cards.
- Headings use Times New Roman/Liberation Serif/generic serif without arbitrary mid-word wrapping; body uses Arial/Helvetica/sans-serif. Typography, spacing and light/divider rhythm carry hierarchy.
- Light mode remains the only supported public theme. Focus rings use `#39583f` (light supporting color on the dark CTA); motion remains limited to short color transitions and disabled by `prefers-reduced-motion`.
