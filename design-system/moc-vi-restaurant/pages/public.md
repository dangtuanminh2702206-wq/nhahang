# Public website override

The approved editorial preview was adopted as the default public interface on 01/10/2026. No old/new theme switch is present.

- Background: warm cream `#f7f4eb`; foreground: deep olive `#243126`.
- Primary: muted olive `#35563d`; secondary: linen `#d8c8ab`; accent: natural wood `#8d6844`.
- Use cream surfaces and fine stone-colored borders; avoid red, glossy shadows, gradients as decoration, glassmorphism, dense badges and SaaS-style cards.
- Headings use Times New Roman/Liberation Serif/generic serif without arbitrary mid-word wrapping; body uses Arial/Helvetica/sans-serif. Typography, spacing and light/divider rhythm carry hierarchy.
- Light mode remains the only supported public theme. Focus rings use `#35563d` (light supporting color on the olive CTA); motion remains limited to short color transitions and disabled by `prefers-reduced-motion`.
- Large hero photo and paired actions; alternating space photography, compact dish listings and category tabs. Missing assets keep MediaPlaceholder. Native labels, focus and keyboard-operable FloorPlan are retained.
- Contact and reservation are public demo routes. Reservation never submits/stores guest data or checks real availability. Missing address/phone/email remain explicitly unprovided; no fabricated map. Phase 3 still awaits missing images.
