# Public website override

Source direction from the Phase 3A brief overrides the generated general palette in `MASTER.md` for all public pages.

- Background: warm cream `#f7f4eb`; foreground: deep olive `#243126`.
- Primary: muted olive `#35563d`; accent: natural wood `#8d6844`.
- Use cream surfaces and fine stone-colored borders; avoid red, glossy shadows, gradients as decoration, glassmorphism, dense badges and SaaS-style cards.
- Headings use a high-contrast editorial serif system stack; body uses an accessible system sans stack. Typography, spacing and light/divider rhythm carry hierarchy.
- Light mode is the only supported public theme in Phase 3A. Focus rings use `#35563d`; motion is limited to short opacity/color transitions and disabled by `prefers-reduced-motion`.
